--------------------------------------------------------------------------------
4. PHYSICAL EXPLANATION: WHY COLOR-OPPONENT FEATURES ARE BRIGHTNESS-INVARIANT
--------------------------------------------------------------------------------

  Brightness perturbation in our experiment is ADDITIVE:
    I'(x,y) = I(x,y) + delta

  This means all three color channels (R, G, B) are shifted by the same amount.

  A color-opponent filter computes a DIFFERENCE between color channels:
    f(x,y) = w_R * R(x,y) + w_B * B(x,y)   where w_R > 0, w_B < 0

  Under additive brightness change:
    f'(x,y) = w_R * (R + delta) + w_B * (B + delta)
            = w_R * R + w_B * B + (w_R + w_B) * delta
            = f(x,y) + (w_R + w_B) * delta

  If w_R + w_B is close to 0 (balanced opponent), the additive term vanishes:
    f'(x,y) ~ f(x,y)

  This is why color-opponent features are naturally invariant to additive
  brightness changes -- the brightness shift cancels out in the difference.

  In contrast, GRAYSCALE or LUMINANCE features compute a WEIGHTED SUM:
    g(x,y) = w_R * R + w_G * G + w_B * B   where all w > 0
    g'(x,y) = g(x,y) + (w_R + w_G + w_B) * delta

  Here (w_R + w_G + w_B) >> 0, so the brightness shift fully propagates,
  causing the cost landscape to deform under illumination change.

--------------------------------------------------------------------------------
5. PRACTICAL IMPLICATIONS FOR COMO SYSTEM
--------------------------------------------------------------------------------

  a) For maximum brightness robustness, prioritize Color-Opponent channels
     (especially R-B opponent) over Edge or Luminance channels.

  b) The current Gray baseline (weighted sum of R,G,B) is fundamentally
     disadvantaged under brightness change -- it has zero color-opponent
     component.

  c) Edge channels (e.g., Ch42, Ch60) provide useful spatial structure
     information but are more sensitive to brightness change (lower Ret50).
     They may be valuable for TEXTURE-RICH regions but less reliable under
     illumination variation.

  d) The ideal channel selection for a robust SLAM system should combine:
     - 1-2 strong Color-Opponent channels (for brightness invariance)
     - 1-2 Edge channels (for spatial structure in normal conditions)
     However, our forward greedy results show that adding Edge channels
     to Color-Opponent channels DILUTES the normalized Sharpness metric.
     Whether this dilution hurts actual SLAM tracking accuracy requires
     ATE (Absolute Trajectory Error) evaluation on real sequences.
