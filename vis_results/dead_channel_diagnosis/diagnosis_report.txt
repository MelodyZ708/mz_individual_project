Dead Channel Diagnosis Report
============================================================

Pipeline: Input RGB → ImageNet Normalize → Conv1 (7x7, stride=2) → BN → ReLU

FINDING: Dead channels are caused by the BN + ReLU combination.
The BN layer uses running statistics learned on ImageNet.
For certain channels, the TUM indoor scene inputs produce conv1 outputs
that, after BN normalization with ImageNet statistics, are entirely negative.
ReLU then clips these to zero, producing 'dead' channels.

This is a DOMAIN GAP effect, not a bug:
- The filters themselves are functional (Stage 1 shows non-zero output)
- BN shifts the distribution based on ImageNet expectations
- When TUM input doesn't match ImageNet distribution for that filter,
  the BN output falls entirely below zero
- ReLU eliminates the signal

IMPLICATION: Using conv1 features without ReLU, or with a different
activation (e.g., LeakyReLU), would recover these channels.
Alternatively, re-computing BN statistics on TUM data (BN recalibration)
would shift the distributions back to a useful range.
